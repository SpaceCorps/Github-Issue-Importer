Contact & Developer Support

We welcome bug reports, feature suggestions, and questions regarding GitHub Issue Importer. Below are the official contact and support channels available.

Primary Support Channels

  • GitHub Issues: For reporting bugs, unexpected behavior, and enhancement proposals, visit github.com/SpaceCorps/Github-Issue-Importer/issues.
  • GitHub Discussions: For questions about importing workflows, CI/CD integrations, and agent orchestration, visit github.com/SpaceCorps/Github-Issue-Importer/discussions.
  • SpaceCorps Organization: To explore our broader suite of agentic CLIs and tools, visit github.com/SpaceCorps.

Security Reporting

If you discover a security issue or potential vulnerability in credential storage or token handling, please use GitHub's Private Vulnerability Reporting on the repository page or reach out directly to the maintainers at security@spacecorps.dev.
