GitHub Issue Importer (`gh-issue-import`) is 100% free and open-source software maintained by SpaceCorps.

## GitHub Platform Usage
The CLI communicates directly with GitHub's REST API using your personal or organization credentials:
- **Free GitHub Accounts**: Standard GitHub rate limits apply (5,000 requests per hour for authenticated accounts).
- **GitHub Enterprise / Organization**: Enterprise rate limits and fine-grained permissions apply according to your GitHub plan.
- **Zero Third-Party Fees**: There are no proxy servers, subscriptions, or telemetry fees. All interactions occur directly between your machine and GitHub.
